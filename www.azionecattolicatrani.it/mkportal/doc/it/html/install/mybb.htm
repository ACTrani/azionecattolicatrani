Come installare MKPortal con MyBB

Attenzione:

  • Questa versione di MKPortal richiede MyBB 1.2.x.
  • Prima di installare questo prodotto, si consiglia di effettuare un backup del database.
     
 

Installare MKPortal è molto semplice:

  1. Il pacchetto d'installazione (il file .zip) contiene la cartella "upload": devi trasferirne tutto il contenuto sul tuo spazio web (per esempio http://www.example.com) seguendo questo schema:

    /forum (o qualsiasi altro nome contenga di cartella che contenga il forum installato)
    /mkportal (ove verrà copiato il contenuto della cartella "upload")
    /index.php (file incluso nel pacchetto di MKPortal)

    Dovresti ottenere questa struttura (è l'unica struttura per far funzionare correttamente mkportal):

    http://www.example.com/forum
    http://www.example.com/mkportal
    http://www.example.com/index.php     (index principale di mkportal)

    Se adesso l'index.php della tua board si trova nella radice del tuo spazio web, devi spostare la board in una sottocartella in modo da ottenere lo schema di cui sopra.


     
  2. Dai i permessi in scrittura (chmod 777) ai seguenti file, cartelle ed ai file ivi contenuti:

    mkportal/conf_mk.php
    mkportal/cache
    mkportal/blog
    mkportal/blog/images
    mkportal/templates/*
    mkportal/lang/*
    mkportal/modules/downloads/file
    mkportal/modules/gallery/album
    mkportal/modules/gallery/album/tmp
    mkportal/modules/reviews/images
    mkportal/modules/reviews/images/tmp
    mkportal/blog/images/tmp


     
  3. Ora puoi avviare lo script d'installazione digitando l'url:
    http://www.example.com/mkportal/mk_install.php

    Segui le istruzioni che appaiono a video


     
  4. Cancellare il file mk_install.php e la directory mkportal/upgrades dal server.

L'installazione è terminata!!
Buon divertimento!!
