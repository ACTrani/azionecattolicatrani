Come Aggiornare MKPortal per phpBB

Attenzione:

  • Questo è solo un upgrade!! E' necessario aver installato già MKportal M1.x
  • Con queste istruzioni non è possibile aggiornare da versioni precedenti alla M1.0, M1.1 Rc1, o M1.1.
 


Per aggiornare la tua versione di MKPortal dalla M1.x alla M1.1.1 occorre:

  1. Attenzione: Prima di uploadare i file di Mkportal M1.1.1 dovete cancellare la vecchia directory mkportal/include
  2. Trasferire i file contenuti in questo pacchetto nel tuo spazio web sovrascrivendo tutti i file eccezion fatta per mkportal/conf_mk.php e /lang/*/lang_blocktitle.php.
    (è necessario anche sovrascrivere l'index.php di MKportal).
  3. Dai i permessi in scrittura (chmod 777) ai seguenti file, cartelle ed ai file ivi contenuti:

    mkportal/conf_mk.php
    mkportal/cache
    mkportal/blog
    mkportal/blog/images
    mkportal/templates/*
    mkportal/lang/*
    mkportal/modules/downloads/file
    mkportal/modules/gallery/album
    mkportal/modules/gallery/album/tmp
    mkportal/modules/reviews/images
    mkportal/modules/reviews/images/tmp
    mkportal/blog/images/tmp

  4. Avviare lo script d'upgrade digitando l'url:
    http://www.example.com/mkportal/upgrades/upgrade.php
  5. Cancellare il file mk_install.php e la directory mkportal/upgrades dal server.

Upgrade completato.
