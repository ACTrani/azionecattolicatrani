Come Aggiornare MKPortal per MyBB

M1.1 -> M1.1.1


Per aggiornare la tua versione di MKPortal dalla M1.1 alla M1.1.1 occorre:

  1. Trasferire i file contenuti in questo pacchetto nel tuo spazio web sovrascrivendo tutti i file eccezion fatta per mkportal/conf_mk.php e /lang/*/lang_blocktitle.php.
    (è necessario anche sovrascrivere l'index.php di MKportal).
  2. Dai i permessi in scrittura (chmod 0777) ai seguenti file, cartelle ed ai file ivi contenuti:

    mkportal/conf_mk.php
    mkportal/cache
    mkportal/blog
    mkportal/blog/images
    mkportal/templates/*
    mkportal/lang/*
    mkportal/modules/downloads/file
    mkportal/modules/gallery/album
    mkportal/modules/gallery/album/tmp
    mkportal/modules/reviews/images
    mkportal/modules/reviews/images/tmp
    mkportal/blog/images/tmp

  3. Avviare lo script d'upgrade digitando l'url:
    http://www.example.com/mkportal/upgrades/upgrade.php
  4. Cancellare il file mk_install.php e la directory mkportal/upgrades dal server.

Upgrade completato.

 

< M1.1 -> M1.1.1

M1.1 Final è la prima versione di MKPortal che supporta MyBB. Non esiste una procedura di aggiornamento per l'utilizzo di MyBB da versioni precedenti di MKPortal. Se si desidera aggiornare la versione correntemente utilizzata di MKPortal e utilizzare MyBB come board, occorre seguire la seguente procedura. L'ordine con cui sono stati inseriti i seguenti passaggi è molto importante e occorre eseguirli nella seguente sequenza:

  1. Aggiornare MKPortal alla versione M1.1.1 seguendo le istruzioni specifiche per la board in uso.
  2. Testare l'aggiornamento di MKPortal per assicurarsi che tutto funzioni correttamente.
  3. Convertire la board esistente a MyBB o procedere con una nuova installazione. Assicurarsi di conservare la corretta struttura delle directory richiesta per MKPortal. Visitare il sito ufficiale di supporto di MyBB al fine di trovare i convertitori per MyBB e informazioni riguardanti il supporto alla sua installazione.
  4. Testare la nuova installazione o conversione a MyBB per assicurarsi che tutto funzioni correttamente.
  5. Dopo essersi assicurati che MyBB funzioni correttamente, si può impostare l'utilizzo di MyBB in MKPortal M1.1.1 semplicemente editando in due punti il file /mkportal/conf_mk.php: (1) Impostare $MK_BOARD in "MYBB". (2) Impostare $FORUM_PATH al nome della directory in cui è installato MyBB (es. "forums").

Upgrade completato.
