Comment mettre à jour MKPortal avec SMF

Attention:

  • Attention: SMF 1.1+ est indispensable pour mettre à jour MKportal 1.1.1. Vous ne pouvez pas utiliser MKportal M 1.1.1 avec SMF 1.0.x
  • Ceci est seulement pour une mise à jour, Mkportal M1.x est requis pour cette mise à jour!!
  • M1.0, M1.1 Rc1, ou M1.1 est requis. Vous ne pouvez pas mettre à jour depuis une autre version de Mkportal.
 


Pour mettre à jour MKPortal M1.x à M1.1.1 vous devez:

  1. Important! Avant d'uploader les fichiers de MKportal M 1.1.1 vous devez supprimer le dossier présent dans MKportal M 1.0 : mkportal/include
  2. Envoyez les fichiers de ce pack dans votre site en reécrivant sur tout les fichiers EXCEPTE mkportal/conf_mk.php et /lang/*/lang_blocktitle.php.
    (vous devez reécrire également le fichier index.php de MKportal).
  3. Donnez les permissions d'écriture (chmod 777) a ces fichiers et leurs contenues:

    mkportal/conf_mk.php
    mkportal/cache
    mkportal/blog
    mkportal/blog/images
    mkportal/templates/*
    mkportal/lang/*
    mkportal/modules/downloads/file
    mkportal/modules/gallery/album
    mkportal/modules/gallery/album/tmp
    mkportal/modules/reviews/images
    mkportal/modules/reviews/images/tmp
    mkportal/blog/images/tmp

  4. Vous pouvez commencer Mise à jour en tapant cet adresse:
    http://www.example.com/mkportal/upgrades/upgrade.php
  5. Supprimer le fichier mk_install.php et le dir mkportal/upgrades du serveur
  6. Allez dans votre board administration --> "features and options" et désactivez l'option "local storage of cookies". Si vous ne désactivez pas cette option vous aurez des problèmes de login sur votre portail.

Mise à jour complete.
