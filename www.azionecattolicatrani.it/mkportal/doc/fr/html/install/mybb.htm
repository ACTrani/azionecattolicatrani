Comment installer MKPortal avec MyBB

Attention:

  • MyBB 1.2.x is est requis pour installer cette version de MKPortal.
  • Il est recommandé de sauvegarder sa base de données avant d'installer ce produit.
     
 

L'installation de MKPortal est très simple :

  1. La pack d'installation (fichier zip) contient le dossier "upload". Vous devez transférer le dossier "upload" sur votre espace web (pour exemple http://www.example.com/) dois être de ce type:

    /forum (ou un autre nom de dossier qui contient toute l'installation de VB)
    /mkportal (contenue dans le dossier "upload")
    /index.php (inclu dans le pack mkportal)

    Vous devez obtenir cette structure:

    http://www.example.com/forum
    http://www.example.com/mkportal
    http://www.example.com/index.php       (index de mkportal)

    il y a d'autre possiblité si vous gardez le nom de dossier mkportal
    Si vous avez l'index de votre forum sur la racine du serveur vous devez la déplacer dans un sous-dossier (vu dans l'example ci-dessus).


     
  2. Donnez les permissions d'écriture (chmod 777) a ces fichiers et leurs contenues:

    mkportal/conf_mk.php
    mkportal/cache
    mkportal/blog
    mkportal/blog/images
    mkportal/templates/*
    mkportal/lang/*
    mkportal/modules/downloads/file
    mkportal/modules/gallery/album
    mkportal/modules/gallery/album/tmp
    mkportal/modules/reviews/images
    mkportal/modules/reviews/images/tmp
    mkportal/blog/images/tmp


     
  3. Vous pouvez commencer l'installation en tapant cet adresse:
    http://www.example.com/mkportal/mk_install.php

    Suivez juste les instructions et c'est fait


     
  4. Supprimer le fichier mk_install.php et le dir mkportal/upgrades du serveur

Installation terminé!!
Amusez-vous bien !!!
