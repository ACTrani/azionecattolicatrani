How to Upgrade MKPortal for MyBB

M1.1 -> M1.1.1


To upgrade your version of mkportal from M1.1 to M1.1.1 you have to:

  1. Upload the files contained in this package into your site overwriting all the old files EXCEPT the files /mkportal/conf_mk.php and /lang/*/lang_blocktitle.php.
    (you need to overwrite also the index.php file of MKportal).
  2. Set write permissions (chmod 0777) for the following files and directories and to their content:

    mkportal/conf_mk.php
    mkportal/cache
    mkportal/blog
    mkportal/blog/images
    mkportal/templates/*
    mkportal/lang/*
    mkportal/modules/downloads/file
    mkportal/modules/gallery/album
    mkportal/modules/gallery/album/tmp
    mkportal/modules/reviews/images
    mkportal/modules/reviews/images/tmp
    mkportal/blog/images/tmp

  3. Now you can run the upgrade script by typing the url:
    http://www.example.com/mkportal/upgrades/upgrade.php
  4. Important security notice: Remove the mk_install.php file and the mkportal/upgrades folder from the server.

Upgrade completed.

 

< M1.1 -> M1.1.1

M1.1 Final is the first MKPortal version to support MyBB. There is no upgrade path from earlier MKPortal versions. If you want to upgrade an existing installation of MKPortal and use MyBB you need to follow these steps. The order of these steps is important.

  1. Upgrade MKPortal to M1.1.1 using the instructions for your current board.
  2. Test your upgraded installation of MKPortal to be sure everything is functioning normally.
  3. Convert your existing board to MyBB or start over with a new MyBB install. Be sure to maintain the correct directory structure for MKPortal. Visit the official MyBB support site to find available converters and for MyBB installation support.
  4. Test your newly converted or installed installation of MyBB to be sure everything is functioning normally.
  5. After you are certain that MyBB is working correctly you can convert your existing MKPortal M1.1.1 installation simply by editing /mkportal/conf_mk.php and making two changes. (1) Set $MK_BOARD to "MYBB". (2) Set $FORUM_PATH to the name of your MyBB directory (eg. "forums").

MKPortal Upgrade and Board Conversion completed.
